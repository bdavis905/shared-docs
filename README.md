## How this works

- Every doc is a self-contained page under its own folder (`<doc-name>/index.html`).
- GitHub Pages serves the repo as-is — push to `main` and the site updates in about a minute.
- This repo is **public**: nothing secret goes in here (no keys, no customer data, no prompts).
